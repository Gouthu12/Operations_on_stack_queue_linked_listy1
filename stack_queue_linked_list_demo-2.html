Stack, Queue & Singly Linked List

Try each operation. The message under the diagram explains what happened.

LIFO: the last item pushed is the first one popped. Capacity is 6.

Push a value to begin.

push, pop, peek: O(1) each.

FIFO: the first item added is the first one removed. Capacity is 6.

Enqueue a value to begin.

enqueue, dequeue, front: O(1) each.

Each node holds data and a pointer to the next node. The last pointer is NULL.

Insert a node to begin.

Insert head: O(1). Insert tail, insert at index, delete value, search, traverse: O(n).
